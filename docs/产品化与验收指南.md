# v1.3 产品化与验收指南

目标是可控地完成“识别 → 局部修复 → 保色贴回 → 检查 → 交付”。成功标记必须有证据；不确定结果应保存并说明原因。v1.3 是可以安装、批处理、诊断和回退的工作流版本，模型对未见素材的识别和生成质量仍需要验收。画布标题统一使用中文阶段名；源码类名只在括号中作为搜索/API 对照，完整参数表见 [节点参数与调参指南](参数与提示词.md)。

## 色差原因与改动

v1.2 的选区外像素差检查只能证明范围保护，不能证明选区内颜色正确。旧贴回过程将生成图与整块 Telea 重建图混合；该重建经过 8-bit 量化，且会在复杂纹理边缘产生不同色调。旧对齐过程还会对不足 0.25px 的微小估计偏移进行插值。

v1.3 保留生成图纹理，不混回原遮挡像素，不使用 Telea 作贴回底图。颜色估计只使用遮罩外的配对上下文：低通后作 RGB 鲁棒拟合，留出 1/3 样本验证，平均误差至少改善 15%、90 分位误差不恶化才应用。增益限定为 0.8–1.25、偏置 ±0.08；上下文误差超过 0.1 时不尝试将大范围结构改变当作色差修正。

边缘处理只从选区外延续有界颜色差，不从选区内原图取色，不替换生成纹理。过渡宽度按裁剪缩放比例换算到原图。颜色已匹配时不应用微小修正。数值处理使用 float32 RGB；最终 PNG 仍按 ComfyUI 标准编码。

遮罩的正值定义需要完全修复的范围，不作为混回原图的透明度。SAM/手绘遮罩必须覆盖遮挡、白边和投影；遗漏在遮罩外的像素无法同时保证“不改外部”和“清除遗漏”。

## 智能与范围控制

- 一次视觉推理返回位置、类型、置信度和可见周围材质；低于 0.65 的自动候选不盲修，报告待检查。
- 文字/Logo/矩形/马赛克走 box；不规则贴纸走 SAM。SAM 使用内部定位点和更宽的安全框补全肢体轮廓，仅接受覆盖已有贴纸、置信度足够且面积增长有界的候选，并剔除无关连通区域。宽高比不再单独作为贴纸转矩形的依据。
- 删除了将中央半透明水印固定向下平移的样例规则，按实际图像位置定位。
- 预清理默认 auto：文字和半透明水印保留可见原背景直接编辑；块状遮挡、贴纸和无类型手绘选区使用局部 Telea。可以手动覆盖 none/telea/ns。
- 裁剪节点将原图范围映射为局部坐标并保存在几何报告，贴回使用这些坐标；编辑模型接收可见材质描述。预清理只修改缩小后裁剪的选区内像素，保留 float32 上下文；预清理后使用补全填充区指令，关闭预清理时使用直接移除指令，两种任务自动区分。
- 残留复检分别放大初始修复范围附近相距较远的选区，比较同位置的原图与修复图；置信度达到 0.8、且可识别为实际叠加物的残片才允许二采。单独色差或自然直线不应触发生成修复。任一分区解析失败或有范围外候选时，不能报告为干净。原图参照是可选输入，旧 JSON 仍可运行。
- 二采遮罩与初始遮罩外扩 24px 的范围取交集，SAM 不能重新扩大到无关对象。
- 严重的一采上下文失真跳过残留模型推理，最终返回原图并报告失败。二采接缝恶化、对齐不确定或改动受保护像素时保留一采。

视觉模型的置信度不是经过统计校准的成功概率，自动检测仍可能误检真实图案或漏掉低对比覆盖。

## 最终结果状态

看“最终结果（自动择优）”节点。不要把一采候选或二采候选直接作为自动交付物。

| 字段/状态 | 含义 | 操作 |
| --- | --- | --- |
| `selected_pass=0` + `no_overlay_detected` | 空选区，返回原图 | 检查是否确实没有遮挡 |
| `completed_clean_first_pass` | 一采通过数值检查、视觉复检未报告残留 | 可以进入后续处理，关键素材仍需抽查 |
| `needs_review` | 检测、对齐、颜色、接缝或残留状态未获确认 | 查看 `reasons` 和最终对比 |
| `rejected_first_pass` | 一采上下文严重失真 | 最终图退回原图；修改提示词/种子/选区 |
| `selected_pass=2` | 二采通过接缝与范围检查而被接受 | 仍为 `needs_review`，没有第三次视觉复检 |
| `second_pass_accepted=false` | 未运行二采或二采未通过 | 看 `reasons` 与 `selected_pass` |

数值检查不是语义质量的证明。`outside_mask_max_difference=0` 是范围保护；`color.context_mae_after` 是可见上下文误差；`boundary_jump_excess_p90` 是相对输入的边界色阶增加。默认超过 0.04 的上下文误差或边界色阶增加会标记检查，不能据此确认人物结构或建筑真实性。

## 高效运行与复用

人物或建筑结构容易被重画时，使用 `qwen21_watermark_structure.json` 或 CLI 的 `--structure-protection`。该流程保留原裁剪，采用 384px 上下文与同尺寸 VAE 编码，再用原遮罩控制加噪采样。遮罩外仍由最终贴回逐像素保护；遮罩内的隐藏结构不能据此保证正确。默认开启复检与按需二采，CLI 可用 `--skip-residual` 关闭。应对照原图检查肢体数量、交叠关系、服装轮廓、建筑透视及接触边界；复检未发现叠加物不等于人体结构正确。贴纸轮廓补全及分区复检需同步更新 Python 节点与 JSON。

提示词由检测节点和裁剪节点自动生成；补充填写在 `QWMDetect.edit_prompt`。“实际送入模型的编辑提示词”预览显示 TextEncode 接收的同一字符串。空输入不表示无指令，负向词也不能替代 CFG=1 时的正向约束。

UI 工作流保留定位、遮罩、一采图和报告，适合调试。CLI 默认保存最终图、对比和任务报告，减少诊断图写盘和输出传输。

```powershell
python scripts/run_workflow.py "C:\图片\原图.png" --output "C:\结果\单图"
python scripts/run_workflow.py "C:\图片\原图.png" --debug-output --output "C:\结果\诊断"
python scripts/run_workflow.py "C:\图片\原图.png" --skip-residual --output "C:\结果\快速"
python scripts/run_batch.py "C:\图片" --output "C:\结果\批次" --resume
```

`--skip-residual` 保留数值检查，但不确认残留是否清除，状态标记为 `needs_review`。8GB 显存采用顺序处理，避免并发采样争抢显存；同一服务保留正常模型加载缓存。曾导致本机崩溃的 Qwen 前缀缓存继续设为 off。

批处理单张失败继续，保存单张日志和汇总 JSON。续跑只有在原文件哈希、工作流哈希、复检选项一致且最终文件存在时才跳过；输入或工作流改变会重跑。已经完成的待检查结果也会被续跑跳过，人工复查后要重试时省略 `--resume`。

已保存的正常一采裁剪可以免采样重贴：

```powershell
python scripts/replay_composite.py "已有诊断任务目录" --mask "实际遮罩.png"
```

脚本使用旧对比图中的实际 ComfyUI 输入像素，避免 JPEG 解码差异。SAM/手绘必须提供实际 MASK；不能用检测框代替精细遮罩。默认保色；`--no-color-match --feather 0` 可用于直接贴回诊断。

## 安装与回退

同时安装六个自定义节点和匹配 JSON，重启 ComfyUI，再重新导入。旧浏览器标签按 Ctrl+F5。只覆盖 JSON 或只更新磁盘文件而不重启，运行进程可能继续使用旧算法。

分享包包含代码、UI/API 工作流、运行脚本、公开示例与 SHA-256 清单；不含权重或私人素材。安装器会检查清单并将旧节点备份到 ComfyUI 根目录的 `.qwm-backups`。环境检查使用 `install.py ... --check-only`。依赖安装需要联网，已有依赖时可指定 `--skip-deps`。

## 验收边界

发布前的基本检查包括：正常裁剪重贴不改变颜色和纹理、软遮罩不带回原遮挡、上下文色漂移可校正、分离区域与边缘区域的范围保护、错误坐标/尺寸拒绝、残留裁剪坐标回映射、二采恶化回退、空选区返回原图、前端导入/回导一致、包清单一致。

本机实测和回放记录见仓库的 `TEST_RESULTS.md`。应区分模型完整运行、免采样回放和受控数值测试，不能把单张成功扩展为所有素材成功。

用于无人值守商业处理前，还需用授权的独立样本集按普通文字、半透明、色块、花纹、贴纸、多水印、大图及干净负样本分组，统计定位召回、误修比例、一次通过率、人工检查率、二采收益和 P50/P95 耗时。原始被遮挡像素不存在时只能生成合理内容；以结构连续性与业务验收标准衡量，不能承诺真实像素恢复。
